## PC Optimisation Engine

2nd Year CS Project focusing on data engineering, algorithms and statistics.

Uses multiple parameters to search, validate and optimise a dataset for a PC build which satisfies the user's specific needs. Analyses price to performance using a Pareto frontier method.

## Aim

- Validate search results based on component compatibility from user's input
- Optimise search results from user constraints.
- Find and display intuitively the most Pareto-optimal PC builds.
